# Tutorial Integrasi Vscode Dengan Github di Linux
### 1. Buka terminal dan masuk ke mode root, Selanjutnya ketik:
```
ssh-keygen -t rsa -b 4096 -C "email kamu"
```
Lalu klik "enter" 3x
### 2. Selanjutnya ketik:
```
(cat ~/.ssh/id_rsa.pub)
```
### 3. Lalu salin SSH Key yang sudah muncul
### 4. Selanjutnya buka akun githubmu
### 5. Klik gambar profile di pojok kanan atas dan pilih menu "settings"
### 6. Di pojok kiri pilih menu "SSH and GPG Keys" lalu klik "new SSH Key"
### 7. SSH Key Berhasil Dibuat!
