# Cara Membuat Akun Github
### 1. Buka google chrome/website pencarian lainnya dan ketik "github". Klik pencarian yang muncul di paling atas

### 2. Selanjutnya buat akun dengn klik "create an account"
### 3. Selanjutnya isi email, password, username, country, centang bagian "email preferences", lalu klik "create account"
### 4. Verifikasi email dengan memasukkan kode yang terkirim di gmail
### 5. Login dengan email dan password yang telah dibuat sebelumnya dengan klik "sign in"
### 6. Lalu verifikasi lagi email degan memasukkan kode yang terkirim di gmail
### 7. Akun Github siap digunakan!

## Langkah Tambahan: Membuat Profile Github
### 1. Kalian bisa menambahkan profile di pojok kanan atas lalu klik lagi "profile"
### 2. Isi nama, public email, bio, pronounse, URL, dan social account
### 3. Selanjutnya isi location, time zone, dan connect ORCID ID
### 4. Terakhir klik "update profile
### 5. Profile github berhasil ditambahkan!
